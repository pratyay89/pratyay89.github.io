What I built

  1. Set-associative LRU model

    Built a configurable CPU cache simulator in C++ modeling set-associative LRU caching. It processes a 695,000-address memory trace in 2.5 seconds by parsing each 32-bit address into tag, index and offset fields.

  2. O(1) eviction

    Implemented the cache as a vector of linked lists (sets), using O(1) LRU eviction: shifting tags on access and inserting misses at the LRU position to accurately track hits and evictions per set.

  3. Validation and benchmarks

    Validated correctness across configurable cache size, block size and associativity parameters, achieving 85% hit rates and benchmarking how associativity and capacity affect performance.
