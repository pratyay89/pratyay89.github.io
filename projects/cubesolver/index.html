What I built

  1. Two-phase solver

    Implemented a 3x3 Rubik's Cube solver in C++ on Kociemba's two-phase algorithm, using IDA* search and BFS-built pruning tables. It solves random cubes in 19.5 moves and 26 ms on average, all within 20 moves.

  2. Parallel search

    Parallelized the search into 6 concurrent searches (std::thread, std::atomic, mutex), cutting average solve time from 158 ms to 26 ms (27× faster than the baseline solver).

  3. REST API

    Built a REST API with cpp-httplib, with an LRU cache, limits on concurrent solves, per-visitor rate limits and Redis storage over OpenSSL/HTTPS.

  4. 3D web demo and tests

    Built a dependency-free 3D web demo in JavaScript with animated solution playback and shareable links. Tested with doctest (48 test cases) and ASan, UBSan and TSan.
