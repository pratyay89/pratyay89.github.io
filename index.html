    Implemented CRYSTALS-Dilithium (ML-DSA, the NIST FIPS 204 post-quantum lattice signature scheme) in C across all security levels (2, 3 and 5). Key generation, signing and verification are built as separate CLI tools.

  2. AVX2 assembly kernels

    Optimized performance on x86 with AVX2 assembly kernels: NTT and inverse NTT, pointwise Montgomery multiplication, and 4-way parallel Keccak/SHAKE. Outputs are byte-identical to the reference implementation.

  3. Portable SIMD on Google Highway

    Built a portable SIMD backend on Google Highway that picks the best instruction set at runtime: SSE2 to AVX-512 on x86, NEON and SVE on ARM. One binary runs on any CPU of that architecture.

  4. Multithreaded t-of-n multi-signature

    Extended the scheme into a multithreaded t-of-n multi-signature system with keygen, sign, combine and parallel verify. It links against all three backends and is validated by a negative test suite that rejects 13 forged or tampered inputs per security level.
